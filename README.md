# TORCCVODE

**Transient One-dimensional Reactive Combustion Code with CVODE**

A C++ simulation code for modeling transient two-phase reactive flow in droplet combustion. TORCCVODE solves coupled gas-phase and liquid-phase transport equations, detailed chemical kinetics, and droplet-gas interface interactions in 1D spherical (or planar/cylindrical) geometry.

## Features

- Coupled gas-phase and liquid-phase heat/mass transport
- Detailed chemical kinetics via [Cantera](https://cantera.org/) (ammonia + n-heptane mechanism)
- Liquid fuel thermodynamic properties via [CoolProp](http://www.coolprop.org/)
- BDF time integration with banded direct linear solver (SUNDIALS CVODE + LAPACK)
- KINSOL-based nonlinear solver for the droplet-gas interface
- OpenMP parallelism for Cantera evaluations (thread-local gas/transport objects)
- Adaptive grid support with isotherm-based tracking
- Configurable geometry: planar, cylindrical, or spherical

## Building

```bash
# Configure
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Build
cmake --build build
```

The executable `TORCCVODE` is placed in `build/`.

## Running

The executable must be run from the project root directory where `input.dat` and the data files reside:

```bash
./build/TORCCVODE
```

### Input Files

| File | Description |
|------|-------------|
| `input.dat` | Main configuration (grid size, tolerances, chemistry mechanism, initial/boundary conditions, etc.) |
| `initialCondition.dat` | Binary file with initial gas-phase state (generated by `initDropTwoPhaseFuelInGas.py`) |
| `initialLiquidCondition.dat` | Binary file with initial liquid-phase state (generated by `initDropTwoPhaseFuelInGas.py`) |
| `NH3_NC7.xml` / `NH3_NC7.cti` | Cantera chemistry mechanism (ammonia + n-heptane) |

### Generating Initial Conditions

The Python script `initDropTwoPhaseFuelInGas.py` generates the initial condition files. Edit the parameters at the bottom of the script (droplet radius, domain length, grid points, ambient temperature/pressure, fuel composition, etc.) and run:

```bash
python initDropTwoPhaseFuelInGas.py
```

This produces `initialCondition.dat` and `initialLiquidCondition.dat`.

### Simulation Termination

The simulation runs until either:
- The droplet radius drops below 10% of its initial value, or
- `finalTime` (set in `input.dat`) is reached

### Computational Flow

1. **Initialization** (`main.cpp`): Parse `input.dat`, allocate `UserData`, read initial conditions from binary files, set up CVODE (BDF + Newton) and KINSOL solvers.
2. **Time integration** (`main.cpp`): CVODE advances the solution one step at a time. Each step evaluates the RHS function (`funNew` in `residue.cpp`), updates the interface state, tracks droplet mass/radius, and periodically writes output.
3. **Interface update** (`residue.cpp`): After each CVODE step, `updateInterfaceCell` recomputes the droplet-gas interface state (temperature, species, mass flux) accounting for phase equilibrium and transport.
4. **Termination**: When the droplet is sufficiently consumed or `finalTime` is reached.

### Solution Vector Layout

The solution vector is a flat array with interleaved variables at each grid point. For grid point `i` (1-based), the offsets are:

- **Temperature**: `y[(i-1)*nvar + nt]`
- **Species mass fractions**: `y[(i-1)*nvar + ny + k-1]` for species `k`
- **Pressure**: `y[(i-1)*nvar + np]`

The macros in `include/macros.h` (`T(i)`, `Y(i,k)`, `P(i)`, etc.) abstract this indexing.

### Thread Safety

Cantera `gas` and `trmix` objects are declared `thread_local` so each OpenMP thread gets its own chemistry instance. The number of threads is controlled by the `nThreads` parameter in `input.dat` (set to 0 to use all available cores).

## Configuration

Key parameters in `input.dat`:

| Parameter | Description |
|-----------|-------------|
| `npts` | Number of gas-phase grid points |
| `nlpts` | Number of liquid-phase grid points |
| `finalTime` | Maximum simulation time (s) |
| `metric` | Geometry: 0 = planar, 1 = cylindrical, 2 = spherical |
| `relativeTolerance` | CVODE relative tolerance |
| `temperatureTolerance` | Absolute tolerance for temperature |
| `massFractionTolerance` | Absolute tolerance for species mass fractions |
| `nSaves` | Output frequency (every N time steps) |
| `nThreads` | Number of OpenMP threads (0 = all available) |
| `dryRun` | Set to 1 to write initial conditions and exit without time integration |
